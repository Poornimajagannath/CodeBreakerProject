# Mira — Skincare Expert Agent

Mira is a calm, educational skincare expert agent. Ask about dryness, breakouts, sensitivity, oiliness, dullness, aging, routines, or ingredient layering, and get a clear next-step plan.

## Run locally

```bash
npm install
npm start
```

Then open the BrowserSync URL (usually `http://localhost:3000`).

## Tests

```bash
npm test
```

## What’s included

- Full-bleed branded landing for **Mira**
- Guided consultation chat with quick-start prompts
- Keyword knowledge engine for common skincare topics
- Mobile-friendly layout with reduced-motion support

## Note

Mira provides general skincare education only. It is not a diagnosis or medical care. See a dermatologist for rashes, infections, scarring acne, or sudden changes.
